# Character portraits

These Duel Links character portraits were obtained from Yugipedia's character portrait image category:
https://yugipedia.com/wiki/Category:Yu-Gi-Oh!_Duel_Links_character_portrait_images

Each PNG is named for its corresponding opponent ID. The Yugi opponent uses Yami Yugi's portrait; Exodia Seeker uses Rare Hunter's portrait. Both Jaden decks share the Jaden Yuki portrait. Gravekeeper is a generic themed opponent and has no character portrait.
