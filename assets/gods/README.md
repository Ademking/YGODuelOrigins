# Egyptian God summon artwork

Downloaded from the three image links supplied by the project owner.
These WebP files retain the source image dimensions and transparency, encoded at quality 90.
They are served locally; the game never requests the original image hosts.

- ra.webp: The Winged Dragon of Ra, Matteste, DeviantArt image dghzmix.
- obelisk.webp: Obelisk the Tormentor, DeviantArt image dbna2n5.
- slifer.webp: Slifer the Sky Dragon, Matteste, DeviantArt image dghzrdx.
